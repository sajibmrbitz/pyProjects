# 🎓 Realistic CG Calculator

A dynamic and user-friendly web application built with Python to effortlessly calculate your semester CGPA. 

🌍 **Live Demo:** [Click here to use the app!](https://sajib-cgcalculator.streamlit.app/)

## Features
- **Interactive UI:** Clean and modern interface powered by Streamlit.
- **Dynamic Course Entry:** Add multiple courses with details like Course Name, Title, Achieved GPA, and Credits.
- **Real-time Tracking:** View all added courses in an organized, auto-updating table.
- **Accurate Calculation:** Computes the semester CGPA instantly using standard university grading formulas.

##  Technologies Used
- **Python** - **Streamlit** :For the web framework and UI
- **Pandas** :For data structuring and table rendering

## 💻 How to Run Locally

If you want to run this project on your local machine, follow these steps:

1. Clone the repository and navigate to the project directory:
   ```bash
   cd path/to/cgCalculator

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt

3. Run the Streamlit server:
   ```bash
   streamlit run main.py
   
4. Open the provided Local URL in your web browser.
