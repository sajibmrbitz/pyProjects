## pyCalculator (with GUI)

A simple mobile-style Graphical User Interface (GUI) calculator built with Python's `tkinter` library.

## Features
- **Modern UI:** Clean, dark-themed interface resembling a smartphone calculator.
- **Dual Input Mode:** Supports both mouse clicks and direct keyboard typing.
- **Keyboard Shortcuts:** Press `Enter` to evaluate and `Backspace` to delete the last character.
- **Smart Evaluation:** Standard mathematical operations with error handling (e.g., division by zero).

## How to Run
Since this uses Python's built-in `tkinter`, no external installations are required.

1. Open a terminal or command prompt.
2. Navigate to the directory containing the script.
3. Run the following command:

```bash
python main.py
