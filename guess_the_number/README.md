# Guess the Number

A simple Python console game where the user attempts to guess a randomly generated number between 1 and 100.

## Features
- Validates user input to prevent crashes from non-integer entries.
- Provides directional feedback ("Too high" or "Too low").
- Alerts the user when their guess is within 10 units of the secret number.
- Tracks the total number of attempts.
- Displays a final performance verdict based on the number of attempts.

## How to Run

1. Ensure Python is installed on your system.
2. Open a terminal or command prompt.
3. Navigate to the directory containing the script.
4. Run the following command:

```bash
python main.py
