# pyProjects

A showcase of my beginner and intermediate Python projects focused on building practical applications, from command-line tools to graphical interfaces and web applications.

## 📂 Projects Overview

### 1. Guess the Number
A simple console-based game built with basic Python logic. The user attempts to guess a randomly generated number with dynamic feedback and a final performance verdict.

### 2. pyCalculator
A Graphical User Interface (GUI) calculator built using Python's `tkinter` library. It features a modern, mobile-like interface with dual input modes (mouse and keyboard) and robust error handling.

### 3. Realistic CG Calculator
A dynamic web application built with **Streamlit** to easily calculate semester CGPA. It features real-time data tracking and a clean user interface. 
- **Live App:** [Realistic CG Calculator](https://sajib-cgcalculator.streamlit.app/)
